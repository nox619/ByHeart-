# ByHeart – Intelligent Memorization Assistant

**Capstone Project | AI-Driven Learning Tool**

## 📌 Project Overview

[cite_start]ByHeart is a memorization assistant that leverages Computer Vision and Speech-to-Text to help users master rote learning[cite: 24, 25, 26]. [cite_start]It ensures effective recall by monitoring gaze and providing real-time accuracy scoring during recitation[cite: 25, 26].

## 🚀 Features

  * [cite_start]**Multimodal Input:** Supports text processing through OCR and direct input[cite: 26, 27].
  * [cite_start]**Gaze Detection:** Integrated computer vision to monitor if a user is looking at the screen during a session[cite: 25, 27].
  * [cite_start]**Speech-to-Text Comparison:** Live transcription of voice input compared against the source text for accuracy scoring[cite: 26, 27].

## 🛠️ Technical Stack

  * **Frontend:** React.js, CSS
  * **Backend:** Python (Flask), SQLite
  * [cite_start]**AI/ML:** Computer Vision (OpenCV), OCR, Speech-to-Text [cite: 25, 26, 27]
